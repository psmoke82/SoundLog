### 🚀 앨범 자켓 전송 옵션 3종 추가, 앱 버전 출력 & 기본 설정 디폴트값 변경 (SoundLog v1.0.23)

#### 📱 주요 반영 및 개선 사항

1. **앨범 자켓이미지 전송 사용자 설정 옵션 3종 추가 (Settings Screen)**:
   - 🔘 **1. 미전송**: 기존처럼 곡제목/아티스트 정보 텍스트만 텔레그램으로 전송.
   - 🔘 **2. Shazam**: Shazam 앱 UI 클릭 ➔ 스와이프를 통한 앨범 자켓 스크린샷 캡처 이미지 전송.
   - 🔘 **3. iTunes API**: iTunes Open API를 통해 1000x1000 고화질 원본 커버아트 URL을 0.1초 만에 가져와 텔레그램으로 전송.
   - '텔레그램 메시지 포맷 설정' 카드 내부 아래쪽에 직관적으로 통합 배치되었습니다.

2. **설정 화면 최하단 앱 버전 표기**:
   - 설정 탭 최하단(저장 버튼 아래)에 현재 앱 버전(`SoundLog v1.0.23`)을 출력하여 사용자가 쉽게 버전을 확인할 수 있도록 구현했습니다.

3. **동적 서비스 및 로그 저장 설정 디폴트값 변경**:
   - **인식주기**: 2분
   - **최대 타임아웃**: 30초
   - **중복 방지**: 10분
   - **Telegram 재시도**: 2회
   - **최대 로그 저장수**: 1000건

4. **프로젝트 릴리즈 규칙 고정 (AGENTS.md)**:
   - GitHub Release 게시 시 제목(Title)을 수식어 없이 앱이름과 버전명(`SoundLog v1.0.23`)만 사용하도록 규칙 명시 및 고정.
   - GitHub Release 게시 및 Push 후 실시간 HTTP / gh release view 검증 완료 후 사용자에게 알림 제공.
