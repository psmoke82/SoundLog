## 🚀 SoundLog v1.0.29 릴리즈 주요 변경사항

- **앨범 자켓이미지 미전송 버그 수정**:
  - `Shazam` / `iTunes API` 옵션 선택 시 이미지가 전혀 전송되지 않던 버그 수정.
  - `TelegramQueueManager.sendSingleSong()`에서 설정값(`albumArtOption`)을 직접 읽어 옵션별 이미지 획득 로직을 중앙화.
  - `iTunes API`: albumArtUrl이 비어있으면 전송 직전 iTunes API 재호출하여 URL 획득 후 전송.
  - `Shazam`: 스크린샷 파일이 없을 경우 iTunes API로 폴백하여 이미지 전송 보장.
  - `DashboardScreen`의 실시간 인식 결과에서 `albumArtPath`를 `SongResultEntity`에 올바르게 전달하도록 수정.
- **iTunesCoverArtFetcher 검색 성공률 강화**:
  - 아티스트+곡명 조합 쿼리 실패 시, 특수문자 제거 클린 쿼리 및 곡명 단독 쿼리를 단계적으로 폴백하도록 개선.
