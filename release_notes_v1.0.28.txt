## 🚀 SoundLog v1.0.28 릴리즈 주요 변경사항

- **앨범 자켓이미지 전송 사용자 옵션 3종 추가 & UI 레이아웃 개선**:
  - '텔레그램 메시지 포맷 설정' 카드 내부 하단에 '앨범 자켓이미지 전송 옵션'을 통합 배치하여 한눈에 직관적으로 확인할 수 있도록 개선.
  - 🔘 `미전송`, 🔘 `Shazam`, 🔘 `iTunes API` (1000x1000 고화질 커버아트 0.1초 획득) 지원.
- **설정 화면 최하단 앱 버전 출력**:
  - SettingsScreen 최하단(저장 버튼 아래)에 현재 앱 버전(`SoundLog v1.0.28`)이 명확히 출력되도록 구현.
- **동적 서비스 및 로그 저장 설정 디폴트값 변경**:
  - 인식주기: **2분** (기존 5분 ➔ 2분)
  - 최대 타임아웃: **30초** (기존 12초 ➔ 30초)
  - 중복 방지: **10분**
  - Telegram 재시도: **2회** (기존 3회 ➔ 2회)
  - 최대 로그 저장수: **1000건**
